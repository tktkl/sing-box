# sb-manager v0.1.1

本版本修复首次安装和交互菜单的使用问题。

- 安装默认只安装管理脚本和服务，不自动创建节点；安装后输入 `sb` 再选择添加。已有节点不会被删除，重装和升级不会新增节点。
- 添加及切换协议改为完整的 22 项编号菜单；端口、连接地址、凭据、SNI 和证书通过提示完成配置。
- 修改菜单只显示当前协议适用字段，增加名称、连接地址和 Socks 用户名修改。
- 出口、证书、网站、DNS、日志、服务、更新、备份、恢复、导入与维护入口统一提供编号选择；`0` 返回，删除和恢复等操作先显示确认。
- 主菜单支持连续操作，输入错误或一次操作失败后可以返回重试。Token、密码和出口链接隐藏输入。
- 原有完整命令、别名及非交互参数行为保留；`--no-node` 继续兼容，`--with-node` 可显式创建初始 REALITY 节点。

升级后输入 `sb` 打开菜单：

```bash
sudo sb update sh 0.1.1
sudo sb
```

root 用户省略 `sudo`。首次安装见 [README](https://github.com/tktkl/sing-box#安装)。
