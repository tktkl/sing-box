# sb-manager v0.1.3

支持无版本号更新 sing-box 官方最新稳定内核，并在更新前提示配置字段变化。

```bash
sudo sb update sh
sudo sb update core --check
sudo sb update core
```

root 用户省略 `sudo`。`--check` 为可选步骤，仅显示版本、字段变化并校验配置，不替换内核或重启服务。

- 自动识别 amd64/arm64，下载官方稳定版并校验官方 SHA-256 摘要；拒绝预发布、降级、摘要缺失或不匹配。
- 显示新增及移除/迁移的配置字段、官方发行说明和完整报告路径。GitHub 差异列表截断时回退到官方标签源码；检测不完整时明确提示。
- 更新前验证当前运行配置和脚本生成配置。不兼容时保留旧内核，启动或健康检查失败时恢复旧内核、配置和原服务状态；中途强制终止后可在下一条管理命令恢复。
- 保留节点 ID、凭据和独立出口；新字段不会自动启用，需要脚本适配后按需使用。客户端版本仍不设上下限。
- 菜单增加「仅检查」和「更新最新稳定内核」。新安装继续使用已验证的 1.14.4 基准，后续无需修改脚本版本常量即可更新内核。
